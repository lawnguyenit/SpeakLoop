# Project state records

These records keep user intent, approved decisions, proposals, actual implementation, impact, verification, and user acceptance distinct.

- [User intent and decisions](user-intent.md)
- [Implementation state](implementation-state.md)
- [Impact map](impact-map.md)
- [Verification and gaps](verification.md)
- [Product and MVP specification](../product-spec.md)

`approved` means the user chose a behavior. `proposed` means it is a candidate requiring confirmation. `implemented` means code exists. `verified` means evidence passed. `accepted` means the user inspected the result. These states are not interchangeable.
